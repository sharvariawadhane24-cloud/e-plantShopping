# e-plantShopping

## Paradise Nursery — Online Plant Shopping Application

### Project Overview

**e-plantShopping** is a React-based online shopping application for Paradise Nursery, where users can browse and purchase a variety of houseplants.

The application provides a landing page, a categorized plant listing, and a shopping cart. Users can add plants to their cart, increase or decrease quantities, remove items, and view the total cost of their selected plants.

### Features

- Landing page with a background image and company introduction.
- Browse houseplants organized into different categories.
- Add plants to the shopping cart.
- Dynamic shopping cart item count.
- Increase or decrease the quantity of plants.
- Remove plants from the cart.
- Calculate item subtotals and the total cart price.
- Navigation between Home, Plants, and Cart pages.
- Checkout button displaying a Coming Soon message.

### Technologies Used

- React.js
- JavaScript
- Redux Toolkit
- React Redux
- React Router
- CSS
- GitHub Pages

### Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/e-plantShopping.git
   ```

2. Navigate to the project directory:

   ```bash
   cd e-plantShopping
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
